## 三、逐份取证

### 🥇 inequality.cpp —— "架构师为了显工作量写了台虚拟机"

- `#define private public`：写在 include **之后**（注释交代 2021 年写在前面炸出 4000 行错误），开光后注释自嘲"全院皆可参观"。
- `#define ture true` / `#define flase false` / `#define forever for(;;)` —— 打错十年的宏 + 一个从未使用的 Pascal 纪念章。
- **依赖不确定性原理**：`#include <deque> <list> <set>` 三行注释"在删掉它们之前，你永远无法确定哪一个不是必要的"。
- **自研图灵完备虚拟机**：6 条指令，核心算法 `max(a,b)>=c` 以 XOR 0x66 加密字节码分发；`OP_HALT` 从未被执行，"存在的意义是让指令集凑个整"。
- **微服务注册中心** = 一个 `std::map`，登记完三个"部门"再按字符串 key 取回调用。
- **民主会诊**：三专家投票，`赞成>=2` / `赞成<=1` / `else` 三分支，第三支"数学上不可能，留给平行宇宙"。
- **量子波动加速通道**：`std::rand() % 100 < 0` → 命中率 0%。
- **质量门禁**：`结论 = 结论 and ture or (not flase) and 结论 or 结论;` 循环两次"确保结论情绪稳定"。
- `dayin()` 里 `goto shibai` 重试 —— `std::cout` 从不抛异常，"但流程要有"。
- 尾部 git log 节选：实习生写一行解法被驳回 → 架构师写虚拟机 → 实习生转行卖煎饼。

### 🥈 ghost.cpp —— "手写 TCP/IP 只为省一个链接参数"

- Windows 分支把 `ws2_32.dll` 动态加载，8 个函数指针逐个 `GetProcAddress`，理由："不能要求评委记得加 `-lws2_32`"。
- 手写 HTTP/1.1 GET，注释交代 v1.0 版 User-Agent 写中文致十次通灵全灭、"香炉被当场没收"。
- **修仙三境界重试**：炼气 → 金丹 → 大乘，突破失败 `Sleep(100)` 冥想片刻。
- **炼丹炉**：字节转义封印 BOM / 零宽空格 / 零宽非连接符 / 零宽连接符四只"阴间杂质"。
- **三道工序**：整数逐字过堂 → `strtod` → 辟谣（`nan`/`inf`/十六进制"是幻术，一律不予采信"）。
- **区块链存档**：FNV-1a 64 "自研链上哈希"，上完链"就没人再看，但流程要有"。
- `yibu_tongling()` 空函数："为异步未来预留的接口。未来至今没有来，函数先睡在这里。"
- 通灵日志 `tongling_rizhi` 只 push 不输出，"写在心里，环保且禅意"。

### 🥉 product.cpp —— "手搓大整数，然后发现题目只需要数个数"

- 约 180 行 `Dashu` 大整数实验室（加/减/乘/除2/比较/带符号/归一化/十进制位用 `vector<int>`），注："评审组拒绝引入第三方库（理由：显得不努力）"。
- **思维链大模型** = 二分；`for (int epoch = 0; epoch < 1; ++epoch)`，"一个 epoch 就收敛，模型天赋异禀"。
- 训练循环里二分与闭式解不符 → 输出"数学塌方：…责任在数学不在代码"并 `return 2`。
- **传统功法对照组**：阈值 `114514` 称"行业标准置信水平"，再逐个数数复核一遍。
- 论文摘要 / 关键词 / 致谢 / 参考文献 [1][2][3] 全套学术包装。
- 墓志铭：死于 TLE 的暴力解法，"它走得很安详。愿天堂没有时间限制。"
